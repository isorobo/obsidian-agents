# AI Builder Club

> A practitioner-education outlet, built by AI Jason x Inflect Labs, publishing the free "Build AI Agents Course" and companion blog on agent engineering fundamentals.

## Role

AI Builder Club publishes the "Build AI Agents Course", a numbered chapter-and-lesson course on the practical construction of LLM agents. Individual posts carry bylines including AI Builder Club (house byline), Shirley, and Jason Zhou. The outlet is not Anthropic primary material; it synthesises and teaches patterns drawn from Anthropic, OpenAI, and the wider agent-engineering community, and separately publishes commentary on Andrej Karpathy's public talks and posts.

## Contribution to Agent Engineering

- Runs a five-part "AI Agents 101" series that takes a reader from a first agent loop through tools, memory, multi-agent orchestration, and production deployment, with runnable code at every step.
- Publishes a companion commentary track on Andrej Karpathy's 2026 public statements (agentic engineering, Software 3.0, agents.md, the LLM wiki pattern), explicitly distinguishing its own commentary from Karpathy's original words.
- Favours copy-paste-runnable examples and an explicit "start simple, add complexity only on observed failure" teaching stance across the series.

## Key Positions

- Conceptual clarity should precede framework adoption; frameworks obscure the prompt and the loop a beginner needs to see.
- Production agent systems need cost, health, and logging discipline from the first deployment, not retrofitted later.
