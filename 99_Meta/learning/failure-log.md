# Failure Log

One row per failure. A failure with a proximate cause but no design lesson is
not yet processed. Leave it out until the design weakness is named.

Classes come from the taxonomy in
`.claude/skills/learn-agents/references/failure-taxonomy.md`: specification,
reasoning, tool, context, architecture, and evaluation.

| Date | Project | Class | Proximate cause | Design weakness | Principle derived |
|---|---|---|---|---|---|

## Reading this log

A class that appears twice is a standing weakness, not an incident. Say so
plainly and derive a principle.

A row with an empty principle column is unfinished work, not a closed failure.
