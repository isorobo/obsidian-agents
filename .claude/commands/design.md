Run `Skill(learn-agents)` and work its eight gates in order for
`$ARGUMENTS`.

Do not write code. Design mode produces a design, not an implementation.

Hold these three lines through every gate:

- Gate 1 comes first. No learning objective, no project.
- Gate 3 decides whether an agent is warranted at all. Where a script wins,
  say so and stop. A recommendation against building is a valid output.
- Gate 7 calls `Skill(agens)` for the pattern. Do not select one here.

Finish with the architecture triple, the implementation stages, the three
reference cases, and the control levels. Name the first stage and its check.

End with the ledger stamp.
