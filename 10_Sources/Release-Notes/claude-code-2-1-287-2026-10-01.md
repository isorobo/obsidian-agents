# Claude Code 2.1.287

> Claude Code, 2.1.287, 1 October 2026.

## Summary

Version 2.1.287 introduces Claude Mods, described as plugins that can modify deeper behaviour, and a first built-in mod called You should know, in which a side agent watches the session and flags things the user or Claude might miss. It adds URL prompts from MCP servers that speak the 2025-11-25 protocol, an `n:<text>` filter in the agents view, and a `prompt_text` field on the OpenTelemetry `user_prompt` event. Fixes cover `claude -p` and SDK model fallback, hook rewake loops, tool heartbeats to SDK hosts and Bedrock and Vertex model checks. The changelog was read from the repository CHANGELOG.md; the date comes from the GitHub release record.

## New Capabilities

- Claude Mods: plugins may modify deeper behaviour.
- The built-in You should know mod, enabled with `/plugin enable cc-plugin-you-should-know@builtin` (first-party sessions with telemetry on).
- `n:<text>` filter in the agents view matching session names and tasks.
- `prompt_text` on the OpenTelemetry `user_prompt` event, a copy of `prompt` for backends that nest dotted keys.
- URL prompts from MCP servers on the 2025-11-25 protocol, for example to sign in.
- Windows startup warning when denying the Bash tool also turns off PowerShell.
- Self-hosted runner: a built-in REST-only `gh api` where the GitHub CLI is absent.

## Deprecated Features

- None stated in this version.

## Migration Notes

- If an MCP server no longer connects after this update, add `"bareElicitationCapability": true` to its MCP config entry.
- Drop or mask `prompt_text` wherever `prompt` is dropped or masked in telemetry pipelines.
- Opus 4.7+ and Fable now use a 1M context window by default on Bedrock, Vertex, Foundry and the Claude apps gateway, with no `[1m]` suffix. `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` keeps 200K.
- Whole-tool `Bash` allow rules and allowing hooks now prompt for, rather than run, shell writes to files Claude Code's file tools refuse outright.

## Engineering Implications

- MCP configuration: elicitation now supports URL prompts, which can change whether a server connects. Test MCP servers after upgrading, and note that fixes stop a tool call running twice when a server changes protocol version.
- Hooks: hooks configured with `asyncRewake` no longer wake Claude repeatedly when the script file is missing. Hook output summaries no longer double-count internal callbacks.
- Headless and SDK: `claude -p` and SDK sessions no longer repeat a model fallback on every later message after a mid-reply model switch. Tool heartbeats now reach SDK hosts while the response stream stalls.
- Permissions: a dangerous `rm` combined with a redirect to a `~` or wildcard path keeps its always-ask safeguard. Allow rules no longer silently run writes to protected credential locations.
- Cost and context: the larger default context window on cloud providers changes compaction timing and token spend for long runs.
- Authentication and model selection: picking Fable in `/model` on a claude.ai login now saves a default that follows the newest Fable, and `/advisor` pairing checks were corrected.
- Observability: the extra OpenTelemetry field affects how prompts are redacted downstream.
