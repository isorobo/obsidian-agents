# Claude Code 2.1.288

> Claude Code, 2.1.288, 2 October 2026.

## Summary

Version 2.1.288 is a large release focused on reliability of long and unattended sessions. Non-interactive sessions and subagents now continue from a partial response after a mid-response API timeout. Auto-compaction, `--resume` and permission handling received many fixes. Headless sessions now honour SIGTERM when a supervisor sends SIGCONT with it, unattended retry loops give up after three timeouts, and the background command time limit now applies only in unattended sessions. MCP gained a re-authenticate prompt for extra OAuth scope. The changelog was read from the repository CHANGELOG.md; the date comes from the GitHub release record.

## New Capabilities

- Re-authenticate prompt when an MCP server asks for more OAuth scope during a tool call.
- `--max-findings <n>|all` for `/code-review`, reused until `--max-findings default`.
- `$.ui.selection()` for mods, and a built-in `gh api` for cloud sessions without the GitHub CLI.
- Recovery of a prompt cleared with Ctrl+C by pressing Up on the empty prompt.
- Ctrl+F session search and Alt+Up/Down group jumps in the agents view, rebindable in `keybindings.json`.
- `CLAUDE_CODE_DISABLE_STRUCTURED_OUTPUTS` to turn structured outputs off for gateways that reject them.
- `/autocompact` saves the auto-compact window per model.

## Deprecated Features

- `claude project purge` is renamed `claude purge`; the old name still works and prints a notice.

## Migration Notes

- The background command time limit now applies only to unattended sessions (`-p`, Agent SDK, CI, cloud). Terminal, desktop and VS Code sessions have no limit.
- The client-side auto mode classifier ignores an `ANTHROPIC_DEFAULT_SONNET_MODEL` pin naming Claude Sonnet 5.5 or Opus 5.5 and uses Claude Sonnet 5 instead.
- MCP URL prompts from servers that cannot report completion now wait for "I'm done, continue".

## Engineering Implications

- Headless mode (`-p`) and SDK: mid-response timeouts continue from the partial response and thinking-only responses are retried. Headless sessions respect SIGTERM when SIGCONT arrives with it, which matters for supervisors such as `timeout` or systemd. Unattended sessions under `CLAUDE_CODE_RETRY_WATCHDOG` stream again and give up after three timeouts instead of retrying for hours. These changes bear on external cancellation and run control.
- Telemetry: OpenTelemetry `claude_code.tool.blocked_on_user` spans now report source and decision in `-p` and SDK sessions, and unanswered permission asks emit a `tool_decision` event.
- Permissions and hooks: PreToolUse and PermissionRequest hooks that fail to match or serialise now block the call instead of being skipped. A dangerous `rm` inside `bash -c` no longer runs unprompted in bypassPermissions mode. Bash deny and ask rules were hardened under sandbox auto-allow. Path-scoped `.claude/rules` and nested CLAUDE.md files now load when Write or Edit touches their scope. The InstructionsLoaded hook now carries `agent_id` and `agent_type`.
- Subagents: a plugin-defined agent spawned by name runs with its own prompt, tools, `disallowedTools` and effort. The Agent tool in `claude mcp serve` now lists agents.
- MCP: tool calls no longer run twice when a remote result exceeds 16 MB or fails to parse, and large MCP results use less memory.
- Authentication: `/login` now reports a failure when credentials cannot be saved to secure storage, and `/login` in a `--bare` session says which credentials work.
- Resume and context: `--resume` no longer drops context restored by compaction, and long conversations auto-compact instead of failing with "Prompt is too long".
