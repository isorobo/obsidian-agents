# Claude Code 2.1.285

> Claude Code, 2.1.285, 29 September 2026.

## Summary

Version 2.1.285 adds a switch to disable the WebFetch tool, a `claude --desktop` launcher, a `claude plugin configure` command, an `allowedProviders` managed setting that limits which API providers a machine may use, and a cap on non-streaming fallback retries. The bulk of the release is fixes: headless `-p` permission-prompt-tool routing for background subagents, fork subagents inheriting plan mode and `dontAsk`, MCP server listing and toggling in SDK sessions, many `/ultrareview` upload fixes, and several Artifact tool safety fixes. The changelog was read from the repository CHANGELOG.md; the release date comes from the GitHub release record.

## New Capabilities

- `CLAUDE_CODE_DISABLE_WEB_FETCH` environment variable turns off the WebFetch tool.
- `claude --desktop` opens the Claude desktop app on the current directory, or on a session with `--continue` or `--resume <id>`.
- `claude plugin configure <plugin>` shows a plugin's options and which are unset, or saves values read from stdin with `--values-stdin`.
- `claude plugin install --config` accepts `<server>.<key>=<value>` so a bundled `.mcpb` MCP server is configured at install time.
- `allowedProviders` managed setting restricts the API providers a machine may use.
- `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` caps re-sends of a timed-out non-streaming fallback request.
- `/resume` and `claude --resume` now open a session running in the background, and `claude --resume <id> "prompt"` sends the prompt as its next turn.

## Deprecated Features

- None stated in this version.

## Migration Notes

- An `Artifact` allow rule no longer lets the tool publish a file outside the working directories without asking. Add the folder with `--add-dir` for the rule to cover it.
- A tool that sets its own `_meta['anthropic/alwaysLoad']` to false now stays deferred even when its server is set to `alwaysLoad`.
- Plugin installs now refuse an install whose id differs from an installed plugin only in punctuation or capitals.

## Engineering Implications

- Headless and `-p` mode: a background subagent's permission request now goes to `--permission-prompt-tool` instead of being auto-denied. Fork subagents (`CLAUDE_CODE_FORK_SUBAGENT=1`) run their own Agent call in the foreground and keep the parent's permission mode, so they cannot exit plan mode.
- SDK sessions: switching off an MCP server added mid-session now removes its tools, and `set_model` requests (such as `setModel`) now apply the new model's output limit and auto-compact window. `ping` stream events arrive every 30 seconds during a non-streaming fallback with partial messages on.
- Retry budget: a failing streamed request no longer retries up to 21 times, because the non-streaming fallback shares the request's retry budget. This bounds latency and cost under outages.
- Permissions and settings: `allowedProviders` gives administrators a managed control over providers. The PowerShell tool no longer skips deny and ask rules when its parser fails to start. Managed settings read errors from OS denial now warn and continue instead of refusing to start.
- Hooks: synchronous hooks no longer hang while a background process they started holds its output open. Hooks and SDK permission callbacks now see the current plan on ExitPlanMode.
- Authentication: sessions using `ANTHROPIC_AUTH_TOKEN` now load the organisation policy, and sign-in no longer waits forever after the browser reports success.
- For a Claude Code adapter, none of these change the `-p` flag set, but the permission-prompt-tool and fork subagent fixes alter observable behaviour.
